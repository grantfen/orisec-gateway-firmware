Orisec Gateway Firmware

Install the latest firmware onto a Waveshare ESP32-P4-NANO board — straight from this page.

Your browser can’t flash over USB. You must use HTTPS to flash.

Web-based flashing needs Chrome or Edge on a desktop (Web Serial). On other browsers, use the manual method below.

How to install

  1. Open this page in desktop Chrome or Edge.
  2. Connect the ESP32-P4 board to your computer by USB.
  3. Click Connect & Install and pick the board’s serial port.
  4. Choose Install and wait for flashing to finish (~1–2 min).
If the board isn’t detected or the port list is empty, install the USB-serial driver for your adapter (CP210x / CH34x / FTDI), then reload. If flashing fails to recognise the chip, use the manual method below — browser flashing of the ESP32-P4 depends on the bundled flasher supporting it.

Manual install (fallback)

Any OS with Python. Install esptool once (pip install esptool), then:

esptool --chip esp32p4 -p <PORT> write-flash 0x0 orisec-gateway-1.0.5.bin

Replace <PORT> with your serial port (e.g. COM4 on Windows, /dev/ttyUSB0 on Linux). Download the binary: orisec-gateway-1.0.5.bin.
