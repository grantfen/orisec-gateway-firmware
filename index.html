Orisec Gateway Firmware

Install the latest firmware onto a Waveshare ESP32-P4-NANO board — straight from this page.

0%

        
Flashing needs desktop Chrome or Edge (Web Serial). Other browsers: use the manual method below.

      


      
How to install

      
    
        
  1. Open this page in desktop Chrome or Edge.
    2. 
        
  2. Connect the ESP32-P4 board to your computer by USB.
    3. 
        
  3. Click Connect & Install and pick the board’s serial port (usually shown as USB Single Serial / CH343).
    4. 
        
  4. Wait for flashing to finish (~1–2 min). The board reboots automatically when done.
    5. 
      


      

        If the port list is empty or it won’t connect: close any other program using the port
        (serial monitor, terminal, another installer tab), then unplug and replug the board and reload
        this page. If it still won’t connect, hold the board’s BOOT button, tap RESET,
        release BOOT, then click Connect & Install again. Install the USB-serial driver
        (CP210x / CH34x / FTDI) if the board isn’t detected at all.

Manual install (fallback)

      
Any OS with Python. Install esptool once (pip install esptool), then:

      
esptool --chip esp32p4 -p <PORT> write-flash 0x0 orisec-gateway-1.0.6.bin

      

        Replace <PORT> with your serial port (e.g. COM4 on Windows,
        /dev/ttyUSB0 on Linux). Download the binary:
        orisec-gateway-1.0.6.bin.
